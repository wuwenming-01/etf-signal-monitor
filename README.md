# 515980 ETF 六因子量化信号监控系统

云端自动运行版本，支持定时检测和邮件提醒。

## 功能特点
- 📊 **六因子量化评分**：景气、情绪、性价比、流动性、风格、舆情
- 📈 **技术指标**：MACD、KDJ、RSI、布林带
- 📧 **邮件提醒**：检测到买卖信号自动发送邮件
- 💾 **历史数据库**：SQLite存储历史信号

## 信号规则
| 综合评分 | 信号 | 含义 |
|---------|------|------|
| > 75分 | 🟢 买入 | 建议积极买入 |
| 60-75分 | 🟡 观望 | 保持仓位 |
| < 60分 | 🔴 卖出 | 考虑减仓 |

## 快速部署
1. Fork此仓库
2. 在Railway中部署
3. 配置cron-job.org定时任务
